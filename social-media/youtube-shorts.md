## Posting Tips for YouTube Shorts

1. **Hook in the first 2 seconds.** Start with a bold claim or question. Never start with "Hey guys."
2. **Keep it under 45 seconds ideally.** Shorter Shorts get more replays, which boosts the algorithm.
3. **Use text overlays.** Reinforce key points visually since many watch on mute.
4. **End with a CTA.** "Link in description" or "Follow for more" — keep it simple.
5. **Post 3-5 Shorts per week.** Consistency signals to the algorithm that you're an active creator.
6. **Vertical format only.** 9:16 aspect ratio, 1080x1920 resolution.
7. **Use hashtags.** #Shorts is no longer required but niche tags (#adulting, #moneytips) help discoverability.
8. **Repurpose TikTok content.** Remove the TikTok watermark before uploading (re-export the original).
9. **Add chapters/descriptions.** Even for Shorts, a good description with keywords helps search ranking.
